GELO — PROJETO COMPLETO COM MENSAGENS AMIGÁVEIS

Este ZIP contém o projeto completo, e não apenas o patch das páginas.

EXECUÇÃO
1. Extraia todo o ZIP para uma nova pasta.
2. Abra o PowerShell nessa pasta (a pasta onde está pom.xml).
3. Execute: mvn clean spring-boot:run
4. Acesse http://localhost:8080/ ou http://localhost:8080/login.xhtml.

ADMINISTRADOR LOCAL

MENSAGENS DE VALIDAÇÃO
- O nome deve ser preenchido.
- O e-mail deve ser preenchido.
- A senha deve ser preenchida.
- Informe um endereço de e-mail válido.
- O nome deve ter entre 2 e 100 caracteres.
- A senha deve ter entre 6 e 20 caracteres.
- Já existe uma conta cadastrada com esse e-mail.

COMO SUBSTITUIR
Recomendação: extraia este ZIP para uma pasta nova para não misturar arquivos com versões antigas. O banco H2 é gravado em data/gelodb. Se quiser manter contas já cadastradas, copie a pasta data da versão anterior para esta pasta nova, com o servidor parado.
